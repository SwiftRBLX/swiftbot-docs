This page provides the essential configuration options for Swift’s **ERLC Integration** module, which enables seamless remote management and monitoring of your ERLC private server. To enable and configure this module, use the `/setup` command and navigate to the **ERLC Integration** page.

## **In-Game Role**

The **In-Game Role** is a role that players within the linked ERLC private server will be granted. This role is added from the member when they join the in-game server, and removed when they leave the in-game server.
